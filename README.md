---# 🛒 Servidor POS - Sistema de Punto de Venta

Sistema de Punto de Venta (POS) backend y frontend desarrollado para la gestión de ventas, inventario y autenticación de usuarios.

## 🚀 Tecnologías utilizadas

- **Backend:** Node.js, Express.js
- **Base de Datos:** SQLite (`sqlite3`)
- **Seguridad:** JSON Web Tokens (JWT), Bcrypt.js
- **Frontend:** HTML5, CSS3, JavaScript Vanilla

## 🔐 Características principales

- **Autenticación segura:** Registro y Login de usuarios con contraseñas encriptadas.
- **Manejo de Sesiones:** Autenticación basada en JWT guardada en `localStorage`.
- **Lógica de Descuentos:** Promociones dinámicas (2x1, 3x2, porcentaje de descuento).
- **Control de Inventario:** Gestión de productos y ventas.
